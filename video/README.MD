# Ataque em Cadeia: Enumeração SMB e Password Spraying

Este projeto apresenta um laboratório prático de cibersegurança realizado em ambiente virtual controlado e autorizado, com foco em uma cadeia de ataque envolvendo enumeração SMB, criação de lista de usuários, Password Spraying e validação de acesso utilizando Smbclient.

## 🎥 Demonstração em vídeo

Assista à demonstração do laboratório:

▶️ [Ataque em Cadeia: Enumeração SMB e Password Spraying](https://youtu.be/oWSAro5NgTE)

## 🛠️ Ferramentas utilizadas

- Kali Linux
- SMB
- Smbclient
- Wordlist de usuários
- Ambiente virtual controlado

## 📄 Relatório técnico

O repositório também contém o relatório técnico completo com as etapas do laboratório, evidências, enumeração SMB, criação da lista de usuários, execução do Password Spraying, validação de acesso com Smbclient, resultados, análise de segurança e medidas de mitigação.

## ⚠️ Aviso

Este projeto foi desenvolvido exclusivamente para fins educacionais. Todos os testes foram realizados em ambiente virtual controlado e autorizado.
